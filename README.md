# Referencias — Vulnerabilidad del cerebro edad-dependiente

Sitio web estático para GitHub Pages que presenta las diez referencias bibliográficas del proyecto científico **Vulnerabilidad del cerebro edad-dependiente ante insultos neurotóxicos**.

## Publicación en GitHub Pages

En la configuración del repositorio, selecciona **Settings → Pages → Deploy from a branch**, y elige la rama `main` y la carpeta `/(root)`. GitHub servirá `index.html` como página de inicio.

## Archivos

- `index.html`: estructura y contenido de la página.
- `style.css`: diseño responsive, temas claro y oscuro y animaciones.
- `script.js`: tarjetas de referencias, enlaces y botón de copiado.
